# لوحة إنجازات موظفين الرخص التجارية والاستثمارية

## التشغيل
```
cd /home/user/app
npm install            # إذا لزم
PORT=3000 node server.js
```
عند أول تشغيل يتم إنشاء حساب المالك، وتجد اسم المستخدم وكلمة المرور في `data/initial-owner.txt`.
يمكن تحديدها مسبقا بالمتغيرات `ADMIN_USER` و`ADMIN_PASSWORD`.
احذف الملف بعد أن تغيّر كلمة المرور.

## الصفحات
- `/` : صفحة الدخول (اسم المستخدم وكلمة المرور).
- `/dashboard` : لوحة العرض فقط للموظفين والمشاهدين.
- `/owner-console` : الصفحة المخفية للمالك (رفع الملفات، إدارة المستخدمين، الملفات المرفوعة). غير مرتبطة من أي صفحة أخرى، ويجب تسجيل الدخول بحساب المالك.

## تنسيق ملف Excel
- عمود باسم يحتوي كلمة "الموظف" أو "اسم" (مثال: اسم الموظف).
- عمود باسم يحتوي "المنجز" أو "انجاز" (مثال: المنجز من قبل الموظف).
- كل ملف يُضاف إلى الإجمالي السابق، وينسب إلى التاريخ الذي تختاره عند الرفع.
- صفوف "الإجمالي" تُتجاهل تلقائيا.

## ملاحظات
- قاعدة البيانات في `data/achievements.db`، انسخها للنسخ الاحتياطي.
- الجلسات تُحفظ في الذاكرة، لذلك يحتاج المستخدمون لإعادة الدخول بعد إعادة تشغيل الخادم.
